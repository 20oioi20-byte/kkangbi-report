# K5. 운영 규칙 — 업로드 신호등 · 알림 · 이슈 · 결재 · 권한

> Copilot 에이전트 지식 문서 5/5

## 1. 업로드 신호등
기준: 센터의 **마지막 업로드 시각**(일별실적 목록에서 그 센터의 가장 최근 수정 시각)부터 지금까지 지난 일수(내림).

| 신호 | 조건 | 의미 |
|---|---|---|
| 🟢 정상 | 3일 미만 | |
| 🟠 주의 | 3일 이상 7일 미만 | "N일째 업로드 없음" |
| 🔴 경고 | 7일 이상 | "N일째 업로드 없음" |
| ⚪ 기록 없음 | 업로드 기록이 없음 | |

- 숨긴 센터(사용여부=아니오)는 신호등·알림 대상에서 뺀다.

## 2. 미업로드 알림 (메일)
두 알림은 **서로 독립**이다.

| 알림 | 판정 기준 | 기본 발송 시점 |
|---|---|---|
| 📊 실적 미업로드 | 일별실적의 최근 저장일 | 4일째 |
| 📝 이슈/히스토리 미등록 | 이슈 목록의 최근 등록일 | 4일째 |

- 공통 설정: 발송정지, 발송시각, 반복주기(같은 센터에 며칠마다 다시 보낼지).
- 메일 제목·본문 치환자: `{center_name}` 센터명, `{days}` 경과일수, `{site_link}` 센터리포트 링크.
- 수신자: 센터 목록의 담당자(여러 명). 담당자가 없으면 "담당자 미등록으로 건너뜀"으로 기록.
- **즉시 발송**: 관리자가 요청하면 발송시각·반복주기·중복방지를 무시하고 지금 조건에 걸린 센터에 바로 보낸다. "이 센터만 / 전체 센터"를 고를 수 있다.
- 모든 발송은 알림로그에 성공/실패와 실패 사유를 남긴다.

## 3. 이슈 · 히스토리
- 등록: 센터담당자가 날짜·제목·내용만 입력한다. 분류·태그 같은 추가 입력을 요구하지 않는다.
- 확인: 관리자만 "확인함/확인취소"를 할 수 있다. 센터담당자에게는 이 기능을 안내하지 않는다.
- 미확인 이슈: 확인여부=아니요인 이슈. 관리자 요약 시 최대 20건, 제목 + 내용 앞 80자.
- AI 요약 관점: 반복 패턴 / 미해결로 보이는 건 / 특이사항. 최근 50건 이내.
- 이슈가 있는 날짜의 실적을 설명할 때는 그 이슈를 함께 언급한다.

## 4. 문서결재 요청
- 결재 문서는 **서식을 그대로 두고 값만 바꾼다.** 표의 태그·서식은 한 글자도 바꾸지 않는다.
- 값 자리 종류: **내가 채운다**(담당자 입력) / **저절로 나온다**(규칙 계산) / **안 바뀐다**(고정 글자).
- 저절로 나오는 규칙
  | 규칙 | 의미 |
  |---|---|
  | 전월값 | 지난 회차에 저장한 같은 칸의 값 |
  | 차이 | 당월 − 전월 (▲/▼ 표기) |
  | 부가세 | 금액 × 10% |
  | 공급가합계 / 부가세합계 / 총합계 | **부가세를 매긴 칸만** 더한다(인원 같은 칸은 섞지 않는다) |
  | 회차(월) | 선택한 회차를 `2026년 8월`, `8월분`, `2026-08` 등 지정 형식으로 |
  | n번째 요일 | 매월 n번째 ○요일, 쉬는 날이면 다음/이전 평일로 |
  | 말일 기준 | 그 달 말일(쉬는 날 처리 동일) |
  | 비율 | 분자 ÷ 분모 × 100 |
  | 조건 문장 | 값에 따라 문장 전체가 바뀜 |
- 지난 회차가 없으면 전월값·차이는 **빈칸**이다(0으로 채우지 않는다).
- 같은 달을 다시 저장해도 이전 저장을 지우지 않고 **쌓는다**.
- 저장 시 제목의 회차(예: `2026년 8월`)는 새 회차로 바뀐다. 회차가 없는 제목은 그대로 둔다.
- 응대율 같은 비율 칸은 일별 평균이 아니라 `Σ응대호 ÷ Σ인입호`.
- 흐름: 담당자 값 입력 → 초안 생성 → Power Automate 승인 요청 → 승인/반려 결과를 결재요청 목록에 기록.

## 5. 권한
| 대상 | 관리자 | 센터담당자 |
|---|---|---|
| 일별실적 조회 | 전 센터 | **자기 센터만** |
| 실적·근태 업로드 | 가능 | 자기 센터 폴더만 |
| TO·KPI 목표 변경 | 가능 | 불가(조회만) |
| 이슈 등록 | 가능 | 가능 |
| 이슈 확인 처리 | 가능 | 불가 |
| 알림 설정·즉시 발송 | 가능 | 불가 |
| 센터 추가·숨김 | 가능 | 불가 |
| 공휴일 수정 | 가능 | 조회만 |

- 권한은 센터 목록의 **조회권한자** 열과 사이트 **관리자 그룹**으로 통제한다(비밀번호 방식 없음). 에이전트는 「권한확인」 도구가 돌려준 센터 목록만 조회한다.
- 다른 센터 데이터를 요청받으면 "권한이 없어 조회할 수 없습니다"라고 답하고, 관리자에게 요청하도록 안내한다.

## 6. 보안 원칙
- 메일 본문·답변에 개인 연락처, 고객 정보, 원본 파일 내용을 그대로 옮기지 않는다.
- 원본 파일은 업로드자료함에만 보관한다. 외부 공유 링크를 만들지 않는다.
