# K1. 센터 리포트 업무정의서

> Copilot 에이전트 지식 문서 1/5 · 이 문서는 "센터 리포트"가 어떤 업무를 하는지 정의한다.
> 수치 계산 공식은 K4, 데이터 항목 정의는 K2, 파일에서 값을 뽑는 규칙은 K3, 알림·이슈·결재는 K5를 따른다.

## 1. 목적
콜센터 운영 센터들의 **일별 실적과 근태(인원)** 데이터를 한곳에 모아,
- 센터별·기간별 핵심지표를 조회하고
- 목표(TO·KPI 목표값) 대비 달성 여부를 판단하며
- 업로드 누락을 감시해 담당자에게 알리고
- 월간 보고서·결재 문서 초안을 만든다.

## 3. 사용자 역할
| 역할 | 할 수 있는 일 | 할 수 없는 일 |
|---|---|---|
| 관리자(총괄) | 전 센터 조회·비교, TO·목표값 변경, 이슈 확인 처리, 알림 설정, 센터 추가·숨김 | — |
| 센터담당자 | **자기 센터만** 조회, 실적·근태 파일 업로드, 이슈 등록, 결재 요청 값 입력 | 다른 센터 조회, 목표값 변경, 이슈 "확인함" 처리 |

## 4. 업무 흐름 (월간)
1. **매 영업일**: 센터담당자가 원본 파일(엑셀/HWPX)을 센터 폴더에 올린다 → 자동 추출 → 일별실적에 저장.
2. **수시**: 센터담당자가 이슈·히스토리(날짜/제목/내용)를 등록한다. 관리자는 확인 후 "확인함" 처리한다.
3. **매시 정각**: 업로드 누락 점검. 기준일 초과 센터 담당자에게 메일 발송.
4. **월초**: 관리자가 해당 월 TO와 KPI 목표값을 확인·수정한다.
5. **월말~익월초**: 월간 운영보고서 초안 작성 → 결재 요청.

## 5. 기간 구분
| 구분 | 범위 |
|---|---|
| 단월 | 선택한 달 1일~말일 |
| 분기누적 | 해당 분기 첫 달 1일 ~ 선택한 달 말일 |
| 반기누적 | 1월(또는 7월) 1일 ~ 선택한 달 말일 |
| 연초누적 | 1월 1일 ~ 선택한 달 말일 |

- 비교 지표: **전월比**(직전 달 같은 기준값 대비), **전년동월比**(작년 같은 달 대비).

## 6. 영업일과 공휴일
- 영업일 = 토·일·공휴일을 제외한 날.
- 공휴일은 "공휴일" 목록(K2 참조)을 따른다. 대체공휴일은 해마다 바뀌므로 연초에 관리자가 확인한다.
- **일평균** 계열 지표는 영업일만 평균한다(K4 참조). 단, 일별 그래프·일별 조회에서는 주말에 실제 입력된 값을 그대로 보여준다.

## 7. 용어
| 용어 | 뜻 |
|---|---|
| TO | 정원(관리자 TO + 상담사 TO) |
| 재직인원 | 해당일 기준 재직 중인 인원 |
| 투입인원 | 해당일 실제 근무(상담 투입)한 상담사 수 |
| 인입호 / 요청호 | 걸려온 콜 수 |
| 응답호 / 응대호 | 상담사가 받은 콜 수 |
| 응대율 / 응답율 | 응답호 ÷ 인입호 × 100 |
| SL | 서비스레벨(목표 시간 내 응답 비율, %) |
| CPD | 상담사 1인 1일 평균 처리 건수 |
| T-NPS | 거래 기반 고객추천지수 |
| 생산성(IN+OUT) / (IN) / (OUT) | 1인당 처리량. OUT = (IN+OUT) − IN |
| 상시 / 한시 | LG전자 summary 시트의 인력 구분(상시=AS, 한시=성수기) |
| 고지의무·통지의무·목적물소멸 | KB손보정비 접수 유형 |
| 처리율 | 처리건 ÷ 접수건 × 100 (기간 합계 기준) |
| 준수율 | 변경기한일까지 처리한 건 ÷ 변경기한일 도래 건 × 100 |
