# K3. 센터별 파일 추출 규칙

> Copilot 에이전트 지식 문서 3/5 · 원본 파일에서 **어느 시트·어느 행·어느 열**의 값을 가져오는지 정의한다.
> 실제 추출은 Power Automate + Office Scripts(`4-automate/office-scripts/`)가 수행한다. 에이전트는 이 문서로 **업로드 안내와 추출 실패 원인 설명**을 한다.

## 공통 원칙
1. 파일은 센터 폴더(`업로드자료함/센터코드/`)에 올린다. 올리면 자동 추출 흐름이 실행된다.
2. 추출은 **저장이 성공했을 때만** 원본 파일을 "처리완료"로 표시한다. 실패하면 "처리실패" + 사유를 남긴다.
3. 날짜는 엑셀 일련번호, 날짜 형식, `2026-07-14`, `2026.7.14`, `7/14`(연도는 파일 연도) 모두 인식한다.
4. "합계", "평균" 행은 날짜가 아니므로 건너뛴다.
5. 값이 비어 있거나 `#N/A` 같은 오류값, 수식 문자열은 **값 없음**으로 본다. 0과 구분한다.
6. 쉼표(1,348)와 %(97.5%)는 떼고 숫자로 읽는다. 원본 글자는 원본값 열에 그대로 남긴다.

## 1. KB손보부천 (kbsonhae) — 일별 실적 엑셀
- **대상 시트**: 모든 시트를 검사한다.
- **머리글 행 찾기**: 위에서 12행 안에서, 한 행의 글자를 이어붙였을 때 `일자`와 `Call`(또는 `콜`)이 함께 있는 첫 행.
- **머리글은 3단**: 머리글 행부터 아래 2행까지(총 3행)를 한 열의 "경로"로 본다. 병합된 셀은 풀어서 같은 값을 채운다. 경로에 `출근`이 들어간 열은 제외한다.
- **열 찾기**: 경로에 아래 낱말이 **모두** 들어 있는 열. 같은 조건의 열이 여럿이면 순번(0부터)으로 고른다.
- **데이터 범위**: 머리글 + 3행부터. 시트 아래쪽 `출근현황` 요약박스가 시작되는 행 위까지만 읽는다.
- **제외 행**: 제휴상담 인입호와 장기손사 인입호가 둘 다 비었거나 0인 행.
- **날짜 열**: 경로에 `일자`가 있는 열 중 날짜로 읽히는 값이 가장 많은 열.

| 지표키 | 경로 낱말 | 순번 | 형식 |
|---|---|---|---|
| 총원 | 총원 | 0 | 숫자 |
| 제휴CS_소계 | 재적인원, 제휴CS, 소계 | 0 | 숫자 |
| 장기사고_소계 | 재적인원, 장기사고, 소계 | 0 | 숫자 |
| 투입인원_제휴상담 | 투입인원, 제휴상담 | 0 | 숫자 |
| 투입률_제휴상담 | 투입인원, 제휴상담 | 1 | 비율(0.95 → 95.0%) |
| 투입인원_장기사고 | 투입인원, 장기사고 | 0 | 숫자 |
| 투입률_장기사고 | 투입인원, 장기사고 | 1 | 비율 |
| 기타업무_채팅상담 / 지원업무 / 실효안내 | 기타업무, (채팅상담·지원업무·실효안내) | 0 | 숫자 |
| 관리자_팀장 / 특화 / QA / 소계 | 관리자, (팀장·특화·QA·소계) | 0 | 숫자 |
| 교육생_소계 | 교육생, 소계 | 0 | 숫자 |
| 제외_보유계약 | 제외, 보유계약 | 0 | 숫자 |
| 제휴상담_인입호 / 응답호 / 손사지원 / OutCall / 콜백 | Call현황, 제휴상담, (항목) | 0 | 정수 |
| 제휴상담_응답율 | Call현황, 제휴상담, 응답율 | 0 | 비율 |
| 제휴상담_CPD / SL | Call현황, 제휴상담, (CPD·S.L) | 0 | 숫자 |
| 장기손사_인입호 / 응답호 / OutCall / 콜백 | Call현황, 장기손사, Total, (항목) | 0 | 정수 |
| 장기손사_응답율 | Call현황, 장기손사, Total, 응답율 | 0 | 비율 |
| 장기손사_CPD / SL | Call현황, 장기손사, Total, (CPD·S.L) | 0 | 숫자 |

- 근태 열(총원~제외_보유계약)과 실적 열(Call현황~)이 한 표에 있다. **근태만/실적만** 선택 저장할 수 있다.
- 추출 기간(시작일·종료일)을 지정하면 그 기간만 저장한다. 비우면 파일 전체 기간.
- 양식이 바뀌어 "일자별 데이터를 찾지 못함"이 나오면: 머리글 3행의 낱말이 위 표와 같은지 확인하도록 안내한다.

## 2. KB손보정비 (kbjeongbi) — 접수 RAW 엑셀(건 단위)
- **대상 시트**: 위 30행 안에 `처리구분`, `의무위반사항`, `요청일`, `완료일`, `변경기한일` 머리글이 **모두** 있는 시트 전부(여러 시트면 합산).
- **재삽입 머리글 무시**: 데이터 중간에 머리글 행이 다시 나오면(의무위반사항 값이 "의무위반사항"인 행 등) 건너뛴다.
- **유형 분류** (한 건마다, 공백·쉼표·기호를 지운 뒤 판단):
  1. 의무위반사항 또는 처리구분 **어느 쪽에든** `목적물소멸`이 들어 있으면 → 목적물소멸
  2. 의무위반사항 = `고지의무` → 고지의무
  3. 의무위반사항 = `통지의무` → 통지의무
  4. 그 외 → 기타
- **처리 여부**: 완료일이 비어 있지 않으면 처리.
- **일자별 집계**
  - 요청일 기준: `접수_{유형}` +1, `접수_Total` +1. 처리면 `처리_{유형}` +1, `처리_Total` +1.
  - 변경기한일 기준(고지의무·통지의무만): `{유형}_변경기한일_대상건` +1, 처리면 `_처리건` +1, 아니면 `_미처리건` +1.
- **근태는 별도 저장**: 이 파일로는 실적만 저장한다. 근태는 근태 엑셀(5장)로 따로 저장하며, 두 저장은 서로의 값을 지우지 않는다.

## 3. LG전자AS (lge) · LG전자성수기 (lge_seongsu) — summary 시트
- **대상 시트**: 이름이 `summary`인 시트 → 없으면 이름에 summary가 들어간 시트 → 없으면 첫 시트(대소문자 무시).
- **날짜 머리글 행**: 위 45행 안에서 날짜로 읽히는 칸이 가장 많은 행. 그 칸들이 날짜 열이다.
- **항목 이름 열 범위**: 첫 날짜 열 앞쪽(최소 6열, 최대 16열).
- **찾는 항목**(표기 차이 허용 — 공백·줄바꿈 무시, 전각 괄호 허용)

| 지표키 | 시트 표기 |
|---|---|
| TNPS | T-NPS, TNPS |
| 생산성_INOUT | 생산성 (IN+OUT) |
| 생산성_IN | 생산성 (IN) |
| 통화시간_INOUT | 통화시간 (IN+OUT) |

- **대상 행**: 항목 이름이 나온 행부터 다음 항목 이름 전까지의 구간 안에서
  - AS센터는 `상시`, 성수기는 `한시` 그룹의 `Total` 행.
  - 그룹 이름과 Total이 같은 행에 있으면 그 행, 아니면 그룹 이름이 나온 뒤 첫 Total 행.
  - 그룹 이름이 아예 없으면 다른 그룹(AS면 한시) 이전의 마지막 Total 행.
- **값 형식**: T-NPS·생산성은 소수 첫째 자리. 통화시간은 H:MM:SS(엑셀 시간값 0.1667 → 4:00:00).
- **제외 날짜**: 네 항목이 모두 비었거나 0인 날짜.
- 파일 이름에 "성수기"가 있으면 성수기, "AS"가 있으면 AS 센터로 우선 판단한다(같은 양식이라 내용만으로는 구분 불가).

## 4. 평택시청 (pyeongtaek) — 일일업무보고 HWPX
- HWPX는 압축파일이다. 안의 `Contents/section0.xml`을 읽는다. **여러 파일을 한 번에** 올려도 파일마다 날짜를 읽어 따로 저장한다.
- **날짜**: 문서 제목 `민원상담 콜센터 일일업무보고(26.07.24.)`의 괄호 안 → 없으면 파일 이름의 괄호 안. 연도가 두 자리면 2000을 더한다.
- **일자별 실적 표**: 첫 행에 `인입호`·`응대호`·`포기호`·`응대율`·`1일평균상담건수`가 모두 있는 표. `응대현황` 행(없으면 두 번째 행)에서 읽는다.

| 지표키 | 표 머리글 |
|---|---|
| 요청호 | 인입호 |
| 응답호 | 응대호 |
| 응대율 | 응대율(% 기호 제거) |
| 포기호 | 포기호 |
| CPD | 1일평균상담건수 |

- **투입인원**: 첫 행에 `계`와 `관리자`가 있고 `근무인원` 행이 있는 표 → 근무인원 행의 (계 − 관리자).
- **재직인원**: 본문 문구 `※ 콜센터 운영인력 :23명(…)`의 숫자.
- **업무유형별 건수**: 첫 행에 `합계`·`복지`·`교통`·`환경`이 있고 `건수`로 시작하는 행이 있는 표 → 건수 행의 머리글별 값. 비중 = 건수 ÷ 합계 × 100(합계의 쉼표를 반드시 지우고 계산).
- 주말·공휴일 파일도 들어오면 저장한다(날짜는 파일 기준).

## 5. 근태 엑셀 (KB손보정비 · LG전자AS · LG전자성수기 공통)
- **대상 시트**: 이름이 네 자리 숫자(YYMM, 예 `2607`)인 시트 전부.
- **머리글 행**: 위 12행 안에서 (알려진 머리글 수 × 5 + 날짜 칸 수) 점수가 가장 높은 행(10점 미만이면 실패). 알려진 머리글: 성명, 이름, 업무, 팀, 퇴사일, 입사일, 전보일, 근무시간, 사번, No.
- **열**: 성명(또는 이름), 업무(없으면 팀), 입사일, 퇴사일, 날짜 열들.
- **역할 구분**: 업무 열이 있으면 값에 `상담사`가 있으면 상담사, 아니면 관리자. 업무 열이 없으면 팀 값에 관리자·팀장·센터장·총괄·QA·강사·SV·매니저·파트장이 있으면 관리자, 아니면 상담사.
- **출근 표시**: ○ ㅇ O o ◯ ● 중 하나. 입사일 이전·퇴사일 이후 날짜는 세지 않는다.
- **결과(날짜별)**: 상담사 수, 관리자 수, 전체.
  - 재직인원 = 그날 출근 표시된 **전체** 인원(상담사 + 관리자)
  - 상담사_투입인원 = 그날 출근 표시된 **상담사** 수
  - TO = 센터 기본 TO(KB정비 15 / LG AS 19 / 성수기 35). 월별TO가 있으면 그 합계를 쓴다.
- **저장 대상**: 영업일(토·일·공휴일 제외)만. 파일에 없는 날짜는 저장하지 않는다(자동 흐름은 기본값을 채워 넣지 않는다).
- **저장 제외**: 상담사_투입인원이 0인 날짜. 관리자가 "제외" 표시한 날짜.

## 6. LG전자통합 (lge_total) — 직접 입력
- 파일 없이 숫자를 입력한다. TO·재직인원·투입인원(AS/성수기 각각)은 **직전 저장일 값을 기본값으로** 채운다.
- 합계는 저장할 때 자동 계산한다. AS·성수기 중 한쪽만 입력돼도 나머지를 0으로 보고 더한다. 둘 다 없으면 합계도 비운다.
- 월평균 실적(T-NPS, 생산성 IN+OUT, 생산성 IN, 통화시간)은 "대상 월"을 골라 그 달 1일 날짜에 `_월평균` 키로 저장한다.
- 통화시간 입력: 숫자만 넣으면 오른쪽부터 초·분·시로 나눈다(40000 → 4:00:00, 145 → 0:01:45).

## 7. 파일 자동 판별 (어느 센터 파일인가)
| 단서 | 판정 |
|---|---|
| `.hwpx` + 제목 "일일업무보고" | 평택시청 |
| 시트 머리글에 처리구분·의무위반사항·요청일·완료일·변경기한일 | KB손보정비 실적 |
| 머리글에 일자 + Call | KB손보부천 |
| summary 시트 + T-NPS·생산성 | LG전자 실적(파일 이름으로 AS/성수기 구분, 불명확하면 사용자에게 묻는다) |
| YYMM 시트 + 성명·업무 | 근태 엑셀(센터는 업로드한 폴더로 판단) |
